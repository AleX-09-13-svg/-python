# Две стяжки — точный отступ от краёв

Правило: `ilogic/Stiajka/Stiajka_2_inch_fixKrai.iLogicVb`.

Выберите две смежные плоские грани одного тела: узкую грань и пласть.
Для нескольких тел выбирайте по две грани каждого тела.
В окне выберите пользовательский параметр точного отступа от края до центра
стяжки. Список содержит существующие пользовательские параметры;
имена с «отступ» показаны первыми.

При длине общего ребра `L` и отступе `a` центры находятся на расстояниях
`a` и `L − a` от начала ребра. Расстояние между стяжками равно `L − 2a`,
без округления к 32 мм. Например, для длины 607 мм и отступа 50,5 мм
расстояние между центрами составит 506 мм. Обе чашки на второй грани
располагаются соответственно. Размеры связаны с выбранным параметром отступа.

Отдельные модули: `Modules/Stiajka_2_fixKrai_Layout.vb` и
`Modules/Stiajka_2_fixKrai_Dialog.vb`. Общие модули присадки сохраняются.
Для работы добавьте `ilogic/Stiajka` в External Rule Directories.
Журнал: `stiajka_2_fixKrai_ilogic.log` в каталоге `ProjectRoot`.

Проверка компиляции и расчётов без изменения документа:

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule "ilogic/Stiajka/Stiajka_2_inch_fixKrai.iLogicVb" --smoke
```
