# Четыре стяжки — iLogic

Правило: `ilogic/Stiajka/Stiajka_4_inch_fixKrai.iLogicVb`.
Вариант `Stiajka_2_inch_fixCentr.iLogicVb` находится в той же папке.

Добавьте папку `ilogic/Stiajka` в «Конфигурация iLogic → Внешние папки правил».
Главное правило подключает общие модули и `Modules/Stiajka_4_Layout.vb` через `AddVbFile`.
Если правило уже добавлено в Inventor, замените старый путь новым.
Структура и запуск модулей: [инструкция](../ilogic/Stiajka/README.md).

В открытой детали `.ipt` выберите две смежные плоские грани, как для правила 05,
запустите новое внешнее правило и выберите параметр отступа.
Для нескольких тел можно выбрать по две грани каждого тела.

Если длина общего ребра — `L`, выбранный отступ — `a`, то расстояние между
крайними центрами `D = L − 2a`. Два крайних промежутка одинаковы:
`s = floor((D / 3) / 32 мм) × 32 мм`. Средний промежуток равен `D − 2s`.
Центры стяжек от начала ребра: `a`, `a+s`, `L−a−s`, `L−a`.
Например, при `L = 600 мм` и `a = 50 мм` промежутки равны `160`, `180`, `160 мм`,
центры: `50`, `210`, `390`, `550 мм`. Если треть расстояния уже кратна 32 мм,
все три промежутка остаются равными.

Оба эскиза используют контрольный размер общего ребра выбранных граней.
Размер между крайними центрами связан с контрольным размером и параметром отступа;
размер крайнего шага равен одной трети этого расстояния, округлённой вниз
до кратного 32 мм. Зеркальность сохраняется в обоих эскизах.

У каждой стяжки сохранён шкант в 32 мм к середине детали.
Все четыре шканта создаются на первой плоскости; чашки четырёх стяжек — на второй.
Направления, диаметры и глубины берутся из тех же настроек, что у 05.
Соседнее тело определяется по совпадающей грани.

До построения проверяется достаточный шаг и отсутствие пересечений отверстий
с учётом диаметров. При недостатке места уменьшите отступ или выберите более
длинное ребро. Крайний шаг после округления должен превышать 64 мм;
дополнительно проверяются фактические зазоры между отверстиями.
Проверка выполняется при запуске правила; после ручного изменения параметров
в готовой модели нужно самостоятельно проверить зазоры.

Журнал: `stiajka_4_ilogic.log` в корне проекта.

Проверка компиляции и расчётов без запуска модели:

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule "ilogic/Stiajka/Stiajka_4_inch_fixKrai.iLogicVb" --smoke
```
