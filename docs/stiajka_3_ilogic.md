# Три стяжки — iLogic

Правило: `ilogic/Stiajka/Stiajka_3_inch_fixKrai.iLogicVb`.
Три стяжки, три чашки и четыре шканта. В iLogic средняя стяжка смещается по сетке
32 мм и имеет по одному шканту с каждой стороны; в `05_stiajka_3inch.py` остаётся
прежняя схема с равным шагом и двумя шкантами.

Добавьте папку `ilogic/Stiajka` в **External Rule Directories**. Выбирайте грани
в следующем порядке:

1. Узкая грань для присадки.
2. Смежная пласть того же тела.
3. Грань со стороны той крайней стяжки, от которой нужно считать шаг 32 мм.

Третья грань используется только для ориентации; отверстия на ней не создаются.
Она может принадлежать другому телу. Для нескольких комплектов выбирайте грани
последовательно тройками. Все выбранные грани должны быть плоскими.
Во всплывающем окне выберите пользовательский параметр точного отступа от
каждого края до центра крайней стяжки. Список содержит все существующие
пользовательские параметры; имена с «отступ» показаны первыми. Параметры модели
не загружаются. Отмена закрывает окно без построения.

Для длины общего ребра `L` и отступа `a` крайние центры находятся на расстояниях
`a` и `L − a` от начала ребра. Расстояние от крайней стяжки со стороны третьей
грани до средней:
`P = floor(((L − 2 × a) / 2) / 32 мм) × 32 мм`.
Средний центр находится на расстоянии `a + P` от выбранной стороны. Он смещён от
середины в сторону третьей грани менее чем на 32 мм. Если половина расстояния уже
кратна 32 мм, точка остаётся посередине.

База отсчёта — крайняя стяжка, ближайшая к третьей выбранной грани. Сторона
определяется по расстояниям от крайних позиций на общем ребре до этой грани.
Если расстояния одинаковы, правило просит выбрать другую ориентирующую грань.
Ориентация обеих осей проверяется в координатах модели, поэтому
соответствующая чашка смещается в ту же физическую сторону, даже если направления
осей двух эскизов противоположны. Отступ связан с выбранным пользовательским
параметром в выражениях размеров эскизов и включён в `Keep_Excel_Params`.

Два крайних шканта смещены на 32 мм внутрь от крайних стяжек. Дополнительно
у средней стяжки создаются два шканта: по одному на 32 мм с каждой стороны
от её центра. Итого четыре шканта. Размеры обоих дополнительных центров
связаны со средней стяжкой. Перед построением проверяются пересечения всех
отверстий по диаметрам из параметров детали; при недостатке места правило
останавливается до создания эскизов.

Отверстия на обеих гранях строятся после подготовки всех эскизов. При ошибке
транзакция откатывается. Журнал: `stiajka_3_ilogic.log` в каталоге `ProjectRoot`,
заданном в `Modules/StiajkaContext.vb`.

Главное правило явно подключает `Autodesk.Inventor.Interop.dll`. Через
`AddVbFile` оно использует общие модули стяжек, а также собственные
`Modules/Stiajka_3_Layout.vb`, `Modules/Stiajka_3_Dialog.vb` и
`Modules/Stiajka_3_Selection.vb`.
При переносе копируйте всю папку `ilogic/Stiajka`.

Проверка без изменения модели:

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule "ilogic/Stiajka/Stiajka_3_inch_fixKrai.iLogicVb" --smoke
```

Валидатор компилирует правило и все подключённые модули по API установленного
Inventor 2023, проверяет шаг 32 мм, точные крайние отступы, обратное направление
оси, выбор стороны по третьей грани, неоднозначный ориентир,
случай точного попадания в сетку и отказ при пересечениях.
Фактическое построение геометрии нужно проверить в Inventor.
