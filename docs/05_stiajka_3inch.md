# Три стяжки — Python

Запуск: `python 05_stiajka_3inch.py`.

Выберите узкую грань и пласть для каждой пары, как в `05_stiajka_2inch.py`.
Во всплывающем окне выберите пользовательский параметр **точного** отступа
от края до центра крайней стяжки.

Для длины общего ребра `L` и отступа `a` центры расположены на расстояниях
`a`, `L / 2`, `L − a` от начала ребра. Шаг между соседними стяжками равен
`(L − 2 × a) / 2`, без округления к 32 мм. Размер эскиза связан с выбранным
параметром отступа. На второй грани создаются три соответствующие чашки.

Два шканта сохранены: по 32 мм внутрь от крайних стяжек. Поэтому расстояние
между крайними стяжками должно быть больше 64 мм, чтобы шканты не совпадали
с центральной стяжкой. При недостатке места скрипт останавливается.

Журнал: `05_stiajka_3inch.log` рядом со скриптом.
