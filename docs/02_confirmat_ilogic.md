# Конфирматы 02 — нативное правило iLogic

Файл: `scripts/Создание присадки/02_Confirmat_Native.iLogicVb`.
Правило работает внутри Inventor и не запускает Python.

## Запуск

1. Откройте деталь `.ipt`.
2. Выберите плоские грани для присадки, как для `02_confirmat.py`.
   Выбирать пары смежных граней, как для стяжки 05, здесь не требуется.
3. Запустите файл как внешнее правило iLogic.
4. В окне выберите три параметра: толщину, отступ от кромки и количество конфирматов.
   В параметре количества должно быть числовое значение `2` или `3`.
   Можно ввести имя параметра вручную. Параметры модели загружаются отдельной кнопкой.

## Построение

На каждой группе граней в одной плоскости создаётся рабочая плоскость,
смещённая на выбранную толщину, и один эскиз. Ось проходит через середины
двух самых коротких прямых проекций рёбер — как в Python 02.

Расстояние между крайними центрами:

`floor((длина оси − 2 × отступ) / 32 мм) × 32 мм`.

Третий центр находится посередине. Для крайних и центральных отверстий
создаются отдельные операции с широким и узким соосными участками.
Глубина широкого участка соответствует выбранной толщине материала.
Другие диаметры и глубина узкого участка берутся из настроек `confirmat`,
из того же JSON, что у Python.

Центральная операция сохраняется с условием подавления `количество = 2`.
При изменении количества на `3` и обновлении модели она должна включаться.
Если API не создаёт ступенчатое отверстие, правило использует две соосные
операции; условие подавления задаётся обеим.

Направление сверления положительное, как при запуске `02_confirmat.py`.
Затрагиваемые тела выбираются по логике Python 02 — все твёрдые тела детали.
Выбор одного соседнего тела из стяжки 05 здесь не применяется.

Все эскизы строятся до сверления, а документ обновляется один раз в конце.
При ошибке транзакция откатывается, перерисовка восстанавливается.
Оформление эскиза не отменяет построение при отказе API цвета или видимости.

Журнал: `02_confirmat_ilogic.log` в корне проекта.
В нём указаны этапы построения, затраченное время и подробности ошибки.

## Проверка

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule "scripts/Создание присадки/02_Confirmat_Native.iLogicVb" --smoke
```

Компиляция проверяет сигнатуры установленного Inventor 2023. Проверка .NET
сравнивает настройки с Python и проверяет расчёты без изменения документа.
Построение геометрии и переключение подавления нужно проверить на детали в Inventor.

Использованные API: [смещение рабочей плоскости](https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-API/files/WorkPlanes_AddByPlaneAndOffset.htm),
[ступенчатое отверстие](https://help.autodesk.com/cloudhelp/2023/ENU/Inventor-API/files/HoleFeatures_AddCBoreByDistanceExtent.htm).
