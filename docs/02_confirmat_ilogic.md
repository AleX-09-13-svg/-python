# Конфирматы 02 — правила iLogic

В папке `ilogic/Confirmat` находятся два варианта:

| Правило | Соответствующий Python |
| --- | --- |
| `Confirmat_2inch_fixCentr.iLogicVb` | `02_confirmat_2inch.py` |
| `Confirmat_5inch_fixKrai.iLogicVb` | `02_confirmat_5inch.py` |

Правила работают внутри Inventor без Python и JSON.

Главные правила явно подключают `Autodesk.Inventor.Interop.dll` через
`AddReference`: эта ссылка нужна также для типов Inventor в модулях `AddVbFile`.

## Запуск

1. Добавьте полный путь к `ilogic/Confirmat` в **External Rule Directories**.
2. Откройте деталь `.ipt` и выберите плоские грани для присадки.
3. Запустите нужное главное правило как обычное внешнее правило iLogic.
4. В окне выберите пользовательские параметры толщины и отступа.

Для `Confirmat_5inch_fixKrai.iLogicVb` выбирайте объекты по порядку: грань присадки,
затем торцевая кромка со стороны базового крайнего конфирмата. Вместо кромки
можно выбрать плоскую торцевую грань. Для нескольких рядов повторяйте такие
пары. Ориентир служит только для выбора стороны; отверстия на нём не создаются.
Вариант на два конфирмата по-прежнему принимает только грани присадки.

Списки содержат все существующие пользовательские параметры; подходящие по
названию показаны первыми. Ввод произвольного имени и загрузка параметров модели
отключены. Параметр количества не нужен.

## Расположение

Ось присадки проходит между серединами двух самых коротких прямых проекций
рёбер грани. Все центры лежат на этой оси. В формулах ниже `L` — длина оси,
`a` — выбранный отступ, расстояния указаны между центрами отверстий.

**Два конфирмата:** расстояние `D = floor((L − 2 × a) / 32 мм) × 32 мм`.
Точки симметричны относительно середины оси: `−D/2` и `+D/2`.
Фактический отступ с обоих краёв равен `(L − D) / 2` и не меньше `a`.
Если не помещается даже расстояние 32 мм, построение отменяется.

**Пять конфирматов:** две пары располагаются зеркально, отступ до ближайшего
центра с каждого края равен `a`. Внутри каждой пары размер закреплён на 96 мм.
Пятый центр смещается в сторону выбранной кромки. Расстояние от крайнего
конфирмата с этой стороны до среднего:
`P = floor(((L − 2 × a) / 2) / 32 мм) × 32 мм`.
Например, для `L = 607 мм` и `a = 50 мм` от крайнего до среднего будет 224 мм,
а смещение от середины — 29,5 мм к выбранной стороне. Если половина пролёта
уже кратна 32 мм, средний конфирмат остаётся посередине.

Между внутренними центрами пар остаётся `L − 2 × a − 192 мм`; это значение
должно быть положительным. После округления средний центр должен находиться
строго между внутренними центрами пар, иначе правило отменяет построение.
Если ориентир равноудалён от обоих крайних центров, выберите другую кромку
или торцевую грань. Центральное отверстие всегда активно, подавления нет.

Размеры эскиза ссылаются на выбранный параметр отступа и измеряемую длину оси.
При последующем редактировании параметров сохраняйте достаточно места для
выбранной схемы: проверка допустимой длины выполняется во время запуска правила.

## Отверстия и модули

На группу граней в одной плоскости создаётся рабочая плоскость со смещением
на выбранную толщину и один эскиз. Глубина широкого участка отверстия равна
выбранной толщине. Другие размеры берутся из параметров детали:
`M_Конфирмат_D_вПласть`, `M_Конфирмат_D_вТорец`, `M_Конфирмат_длина`.

Все центры в эскизе используются в одной ступенчатой операции. При отказе
counterbore API создаются два соосных сверления. Направление положительное;
затрагиваются все твёрдые тела детали. Использованные параметры сохраняются
в выражении `Keep_Excel_Params`.

| Общий модуль | Назначение |
| --- | --- |
| `ConfirmatContext.vb` | Поля, единицы, схема, имена и журнал |
| `ConfirmatWorkflow.vb` | Выполнение, транзакция и обработка ошибок |
| `ConfirmatConfig.vb` | Параметры отверстий и Keep |
| `ConfirmatDialog.vb` | Выбор пользовательских параметров |
| `ConfirmatSketches.vb` | Проекции, эскизы, центры и размеры |
| `ConfirmatReference.vb` | Выбор кромки/грани отсчёта и шаг среднего конфирмата |
| `ConfirmatHoles.vb` | Отверстия и затрагиваемые тела |

Модули подключаются через `AddVbFile` и образуют один класс `ThisRule`.
Все эскизы строятся до сверления; документ обновляется один раз в конце.
При ошибке транзакция откатывается и перерисовка восстанавливается.

Журналы в корне проекта: `02_confirmat_2inch_ilogic.log` и
`02_confirmat_5inch_ilogic.log`. Каталог задаётся константой `ProjectRoot`
в `ConfirmatContext.vb`; при переносе проверьте этот путь.

## Проверка

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule "ilogic/Confirmat/Confirmat_2inch_fixCentr.iLogicVb" --smoke
python -X utf8 -B scripts/validate_ilogic_native.py --rule "ilogic/Confirmat/Confirmat_5inch_fixKrai.iLogicVb" --smoke
```

Валидатор компилирует главные правила вместе со всеми `AddVbFile` по сигнатурам
установленного Inventor 2023 и проверяет явную ссылку на библиотеку Inventor.
Проверка .NET проверяет обе схемы, шаг 32 мм,
отступы, пары 96 мм, среднюю точку по сетке 32 мм для обеих сторон,
ориентирующую кромку и отказ при совпадении среднего центра с крайней парой.
Она не изменяет документ. Фактическое построение нужно проверить в Inventor.
