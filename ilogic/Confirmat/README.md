# Конфирматы — iLogic

Правила запускаются внутри Inventor без Python и JSON:

| Правило | Схема |
| --- | --- |
| `Confirmat_2inch_fixCentr.iLogicVb` | Два конфирмата симметрично. Расстояние между центрами кратно 32 мм, отступ от каждого края не меньше выбранного минимума. |
| `Confirmat_5inch_fixKrai.iLogicVb` | Две пары по 96 мм, точные крайние отступы; средний конфирмат по сетке 32 мм от стороны выбранной кромки. |

В окне выбираются только существующие пользовательские параметры толщины и
отступа. Количество определяется правилом запуска. Отступ связан с выбранным
параметром в размерах эскиза.

Добавьте эту папку в **External Rule Directories** в настройках iLogic.
Выберите плоские грани открытой детали `.ipt` и запустите нужное главное правило.
Для пяти конфирматов выбирайте парами: грань присадки, затем торцевую кромку
или торцевую грань со стороны базового крайнего конфирмата.
Файлы `Modules/*.vb` подключаются через `AddVbFile` как Straight VB code;
отдельно их не запускайте. При переносе копируйте всю папку.

Настройки отверстий находятся в `Modules/ConfirmatConfig.vb`, каталог журнала —
в `Modules/ConfirmatContext.vb`. Журналы: `02_confirmat_2inch_ilogic.log` и
`02_confirmat_5inch_ilogic.log` в корне проекта.

Подробности и команды проверки: [инструкция](../../docs/02_confirmat_ilogic.md).
