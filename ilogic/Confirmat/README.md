# Конфирмат — iLogic

Запускайте `Confirmat_Native.iLogicVb` в Inventor. Добавьте эту папку в
External Rule Directories в конфигурации iLogic, чтобы находились файлы `AddVbFile`.
Если использовалось правило из `scripts/Создание присадки`, замените его путь.

Вспомогательные файлы находятся в подпапке `Modules`; `AddVbFile` указывает пути
`Modules\имя.vb`. В каталоги внешних правил добавляется родительская папка.

Пять файлов `.vb` — части класса `ThisRule`, подключаемые как Straight VB code.
Главное правило запускается как обычное iLogic-правило; отдельно `.vb` не запускайте.

Правило работает без JSON и Python. Имена параметров и настройки операций
заданы в `Modules/ConfirmatConfig.vb`; значения размеров берутся из открытой детали.
Изменения внешнего JSON на правило не влияют. Путь к каталогу журнала задан
в `Modules/ConfirmatContext.vb`. При переносе копируйте всю папку и проверьте этот путь.

Описание структуры, настроек и проверки: [инструкция](../../docs/02_confirmat_ilogic.md).
