# Присадка ящиков

Внешнее правило Inventor: `Yashchiki.iLogicVb`.

1. Откройте многотельную деталь `.ipt`. В ней должен быть положительный параметр длины `Наколка_D`.
2. Выберите с Ctrl три плоские грани в любом порядке: большую прямоугольную грань для эскиза и две взаимно перпендикулярные базовые грани. Каждая базовая плоскость должна проходить через одно из двух смежных рёбер большой грани.
3. Запустите внешнее правило `Yashchiki.iLogicVb`.

Большая грань определяется по площади. Из двух базовых рёбер длинное принимается за нижнюю базу, короткое — за боковую. Размеры откладываются внутрь прямоугольника от их общего угла. Квадратная грань отклоняется, поскольку назначение баз неоднозначно.

Три круга имеют диаметр `Наколка_D`. Их центры расположены на 37, 165 и 261 мм от боковой базы, на 23 мм от нижней. Размеры положения и диаметров задаются ограничениями эскиза; базовые рёбра проецируются ассоциативно.

Выдавливание имеет общую длину 7 мм от плоскости эскиза: 5 мм зазора и 2 мм вычитания в соседнем теле. Правило ищет одно соседнее твёрдое тело с входной плоской гранью на расстоянии 5 мм по нормали к эскизу, с любой его стороны. Проверяются проекции центров и 32 точек окружности каждого круга на эту грань. Направление определяется внутрь соседнего тела, операция заранее ограничивается этим телом. Исходное тело не вырезается.

Если геометрия не подходит, сосед отсутствует или неоднозначен, правило выводит сообщение. Изменения выполняются одной транзакцией и отменяются при ошибке. Повторный запуск создаёт новый эскиз и вырез, а не редактирует предыдущие.

Проверка компиляции без изменения модели:

```powershell
python scripts/validate_ilogic_native.py --rule ilogic/Yashchiki/Yashchiki.iLogicVb
```

Компиляция проверена с API Inventor 2023. Построение на реальной модели требует проверки в Inventor.
