# 07 — Петли, iLogic

`Petli.iLogicVb` — модульное внешнее правило, эквивалент Python-команды 07.
Python для запуска не нужен. Запускайте как обычное
правило iLogic, **без включения Straight VB code**.

1. Добавьте папку `ilogic/Petli` в «Сервис → Параметры → Конфигурация iLogic → Внешние папки правил».
2. Откройте `.ipt`-деталь. Выберите с Ctrl сначала внутреннюю пласть фасада, затем пласть боковины.
3. Запустите `Petli.iLogicVb`.

Главное правило содержит `Main` и подключает файлы из подпапки `Modules`
через `AddVbFile`. При переносе копируйте всю папку `Petli` вместе с `Modules`.
В каталоги внешних правил добавляйте родительскую папку `ilogic/Petli`.
Файлы `.vb` — Straight VB code, части класса `ThisRule` (`Partial Public Class`);
отдельно запускать их не нужно.

| Модуль | Назначение |
| --- | --- |
| `Modules/PetliContext.vb` | Константы, общие поля, типы, имена и журнал |
| `Modules/PetliGeometry.vb` | Геометрия прямоугольника, векторы и пересечение плоскостей |
| `Modules/PetliLayout.vb` | Количество петель, позиции чашек и наколок, проверки размещения |
| `Modules/PetliSketches.vb` | Проекции контуров, общие операции с линиями и размерами |
| `Modules/PetliFacade.vb` | Построение эскиза фасада |
| `Modules/PetliSide.vb` | Построение эскиза боковины |
| `Modules/PetliHoles.vb` | Направления, коллекции центров и отверстия в целевых телах |

Точка запуска — `Petli.iLogicVb`; изменения подключённых модулей относятся к ней.

Нужны две прямоугольные плоские грани без вырезов, перпендикулярные друг другу.
Грани могут принадлежать разным твёрдым телам одной детали.
Параметры детали должны существовать и иметь положительные значения в единицах длины:

| Параметр | Назначение |
| --- | --- |
| `Петля_D_присадки` | Диаметр чашек |
| `Стяжкаh_резьбаШтока_Петля` | Глубина чашек |
| `Наколка_D` | Диаметр всех наколок |
| `Наколка_Глубина` | Глубина всех наколок |

Параметры используются по этим точным именам. Правило читает их из активной детали,
не обращается к Excel/JSON и не создаёт недостающие параметры.

## Геометрия

- Количество петель: менее 1000 мм — 2, от 1000 до менее 1600 — 3,
  от 1600 до менее 2000 — 4, от 2000 — 5. Размер измеряется вдоль кромки со стороны боковины.
- Чашки: 22 мм от кромки, крайние центры по 100 мм от торцов; промежуточные — равномерно.
- Наколки фасада: по две на чашку, 45 мм между центрами,
  ряд смещён на 9,5 мм от центра чашки вглубь фасада.
- Наколки боковины: по две на петлю, на высоте проекции центра чашки.
  Первая — 20 мм от переднего ребра, вторая — ещё через 32 мм (52 мм от ребра).
  Зазор между фасадом и боковиной в отступ не входит.

Создаются эскизы `Petli`, `Petli_Side` и операции `Petli_Holes`, `Petli_Nakolki`,
`Petli_Side_Nakolki`. Имена получают свободный суффикс при повторном запуске.
Оба эскиза строятся до сверления, их коллекции кэшируются, центры подготавливаются
без повторного чтения координат. Положения точек связаны проекциями и размерами.
Направления сверления совпадают с текущей Python-версией 07, включая выполненный разворот.
Каждая операция ограничена соответствующим телом. Ошибка откатывает всю команду.
Тело для `SetAffectedBodies` заново находится по имени после создания отверстий:
перестроение операции может сделать прежнюю ссылку на тело недействительной.
Экранная перерисовка восстанавливается при успехе и при ошибке.

Количество петель выбирается при запуске; пересечение порога размера при последующем
редактировании детали не добавляет петли автоматически. Повторный запуск создаёт
новую присадку: прежнюю следует предварительно отменить либо удалить вместе с эскизами.

Журнал с замерами времени: `07_Petli_ilogic.log` в корне Python-проекта.
При переносе проекта измените константу `ProjectRoot` в `Modules/PetliContext.vb`.

## Проверка

```powershell
python -X utf8 -B scripts/validate_ilogic_native.py --rule ilogic/Petli/Petli.iLogicVb --smoke
```

Проверяется компиляция против API установленного Inventor 2023 и совпадение расчётов
с Python в 24 раскладках: обе стороны, разные размеры, поворот и смещение системы координат.
Проверяются граничные размеры и шесть ошибочных геометрий.
Эта проверка не запускает построение модели; работу правила внутри iLogic следует проверить в Inventor.
