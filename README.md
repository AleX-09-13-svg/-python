# Автоматизация мебельной присадки в Autodesk Inventor

Набор Python-скриптов для создания эскизов и отверстий мебельной присадки в активной `.ipt`-детали Autodesk Inventor через COM.

Основной рабочий режим сейчас завязан на ручной выбор граней в Inventor перед запуском нужной команды. Цвета граней используются только в отдельных вспомогательных сценариях и старой логике, но рабочие команды берут выбранные пользователем грани.

## Требования

- Autodesk Inventor уже запущен.
- Открыта активная `.ipt`-деталь.
- В Inventor выделены нужные грани перед запуском команды.
- Установлены Python и `pywin32`.
- Python и Inventor запущены с одинаковыми правами пользователя, иначе COM-подключение может не сработать.

## Быстрый запуск

Создать эскизы сверления на выбранных гранях:

```powershell
python 00_createSketches.py
```

Создать стяжку по выбранным торцевым и фронтальным граням:

```powershell
python 04_stiajka_2шт.py
```

Создать конфирмат для толщины каркаса МДФ:

```powershell
python 02_confirmat_2шт_Bok16.py
python 03_confirmat_3шт_Bok16.py
```

Создать конфирмат для толщины каркаса ШПОН:

```powershell
python 22_confirmat_2шт_Bok17.py
python 33_confirmat_3шт_Bok17.py
```

Диагностика эскизов:

```powershell
python inspect_sketches.py
```

## Как работает стяжка

`04_stiajka_2шт.py` ожидает выбранные грани минимум в двух плоскостях:

- торцевые грани, на которых создаются основные эскизы сверления;
- одна или несколько фронтальных граней, на которых создаются эскизы чашек.

Скрипт сам делит выбранные плоскости на торцевую и фронтальные через эвристику смежности граней. После этого он:

1. Проверяет наличие нужных пользовательских параметров.
2. Создаёт новые эскизы сверления на торцевых гранях.
3. Создаёт эскизы чашек на фронтальных гранях.
4. Создаёт отверстия стяжки из этих эскизов.
5. Скрывает рабочие эскизы.
6. Выполняет один финальный `doc.Update()` после скрытия эскизов.

Внутренний `Update` при создании отверстий для этого выбранного сценария отключён, чтобы не обновлять модель дважды.

## Как работает конфирмат

Скрипты конфирмата используют выбранные грани, создают смещённые эскизы через `001_createSketches_for_Conf.py`, затем создают отверстия:

- `02_confirmat_2шт_Bok16.py` - 2 точки, параметр толщины `Толщина_каркаса_МДФ`;
- `03_confirmat_3шт_Bok16.py` - 3 точки, параметр толщины `Толщина_каркаса_МДФ`;
- `22_confirmat_2шт_Bok17.py` - 2 точки, параметр толщины `Толщина_каркаса_ШПОН`;
- `33_confirmat_3шт_Bok17.py` - 3 точки, параметр толщины `Толщина_каркаса_ШПОН`.

Скрипты добавляют/обновляют служебный параметр `Keep_Excel_Params`, чтобы удерживать импортированные из Excel параметры от удаления Inventor.

## Эскизы сверления

Для каждой выбранной грани строится:

- ось по центру двух коротких рёбер;
- пять точек на оси: левая крайняя, левая внутренняя, центральная, правая внутренняя, правая крайняя;
- размеры и зависимости, привязанные к пользовательским параметрам отступа.

Цвет рабочих эскизов фиксированный жёлтый: `RGB (255, 220, 0)`.

Шаг между точками кратен `32 мм`. Расстояние между крайними точками считается по формуле:

```text
floor((Long_edge_N - отступ * 2) / 32 мм) * 32 мм
```

Параметр отступа выбирается автоматически:

- если длинное ребро больше порога из `settings.json` (`drilling.drawer_edge_max_cm`), используется параметр каркаса;
- иначе используется параметр ящика.

## Параметры Inventor

Общие параметры эскизов:

```text
Минимальный_отступ_присадки_от_кромки_Каркас
Минимальный_отступ_присадки_от_кромки_Ящик
```

Для конфирмата также нужны параметры толщины:

```text
Толщина_каркаса_МДФ
Толщина_каркаса_ШПОН
```

Параметры стяжки, конфирмата, шкантов и служебные коды Inventor задаются в `settings.json`. Если параметра нет в активной детали, скрипт покажет окно со списком отсутствующих параметров и остановится.

## Настройки

Основной файл настроек:

```text
settings.json
```

Важные секции:

- `inventor_api` - числовые коды Inventor для направления отверстий и ориентации размеров;
- `drilling` - порог выбора отступа для каркаса/ящика;
- `confirmat` - диаметры, глубины, направления и имена операций конфирмата;
- `stiajka` - пользовательские параметры и операции стяжки.

Размеры можно задавать строками с единицами Inventor, например `"5 mm"` или `"35 mm"`, либо именами пользовательских параметров детали.


## Проверки

Проверить синтаксис Python-файлов:

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$files = Get-ChildItem -Recurse -Filter *.py | ForEach-Object { $_.FullName }
python -m py_compile $files
```

Проверить JSON:

```powershell
python -m json.tool settings.json
```

Полную функциональную проверку нужно делать в Inventor на копии детали, потому что основная логика работает через COM и создаёт реальные эскизы/отверстия в активном документе.

## Важно

- Перед запуском рабочей команды обязательно выделите грани в Inventor.
- Для стяжки выбирайте торцевые и фронтальные грани вместе.
- Для неоднозначных наборов граней эвристика стяжки может выбрать не ту торцевую плоскость.
- Рабочие скрипты скрывают использованные эскизы после создания отверстий.
- Перед массовым запуском лучше проверить результат на копии детали.
