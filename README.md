# Автоматизация мебельной присадки в Autodesk Inventor

Проект создает эскизы и элементы мебельной присадки в активной детали Inventor через Python COM.

Главная идея: сначала цветом размечаются нужные грани, потом создаются эскизы, потом запускаются скрипты конкретной присадки.

![Соответствие цветов](docs/color_rules.svg)

## Соответствие Цветов

| Цвет грани | Назначение | Скрипт |
| --- | --- | --- |
| Красный | Конфирмат 3 шт, каркас | `03_confirmat_3штКаркас_на_Красн.py` |
| Желтый | Конфирмат 2 шт, каркас | `02_confirmat_2штКаркас_на_Жел.py` |
| Зеленый | Стяжка, каркас | `01_stiajkaКаркас_на_Зел.py` |
| Синий | Стяжка, ящик | `01_stiajkaЯщик_на_Син.py` |

## Обязательные Условия

- Autodesk Inventor уже запущен.
- Активна `.ipt` деталь.
- Python установлен вместе с `pywin32`.
- Python и Inventor запущены с одинаковыми правами, иначе COM может не подключиться.

## Пользовательские Параметры

В детали должны быть параметры:

```text
Минимальный_отступ_присадки_от_кромки_Каркас
Минимальный_отступ_присадки_от_кромки_Ящик
Стяжка_D
Стяжка_h
Стяжка_отступ
```

Если нужного параметра нет, скрипт показывает окно и останавливается.

## Настройки settings.json

Основные размеры и служебные параметры вынесены в `settings.json`. Python-файлы должны хранить логику, а значения диаметров, глубин, направлений и имен элементов лучше менять здесь.

### inventor_api

Этот блок не про мебельные размеры, а про служебные коды Autodesk Inventor API. Обычно эти числа менять не нужно.

`hole_direction` переводит понятные слова направления сверления в числовые команды Inventor:

- `positive: 20993` - сверлить в положительном направлении нормали эскиза.
- `negative: 20994` - сверлить в противоположном направлении.

Эти слова используются ниже в настройках отверстий, например `"direction": "positive"`.

`dimension_orientation` переводит тип размера в числовой код Inventor:

- `horizontal: 19201` - горизонтальный размер.
- `vertical: 19202` - вертикальный размер.
- `aligned: 19203` - размер по линии между двумя точками.

Эти значения используются при создании вспомогательных размеров в эскизах стяжки.

### confirmat

Блок `confirmat` отвечает за конфирмат в файлах `02_*` и `03_*`.

`debug` включает или выключает дополнительные сообщения диагностики в консоли. Обычно стоит `false`.

`outer` задает основное отверстие конфирмата:

- `diameter` - диаметр отверстия.
- `depth` - глубина отверстия.

`inner` задает встречное/внутреннее отверстие конфирмата:

- `diameter` - диаметр отверстия.
- `depth` - глубина отверстия.

Размеры записываются строками с единицами Inventor, например `"5 mm"`, `"35 mm"`.

### stiajka

Блок `stiajka` отвечает за стяжку в файлах `01_*`.

`parameters` задает имена пользовательских параметров Inventor, которые должны быть в детали:

- `diameter` - параметр диаметра чашки стяжки.
- `depth` - параметр глубины чашки стяжки.
- `offset` - параметр отступа бокового эскиза/чашки.

`side_offset` - значение отступа по умолчанию, если параметр `offset` не найден в детали. Внутренние единицы Inventor обычно сантиметры.

`outer_main`, `outer_secondary`, `inner_short`, `inner_long` описывают отверстия стяжки:

- `diameter` - диаметр отверстия.
- `depth` - глубина отверстия.
- `direction` - направление сверления: `positive` или `negative`.
- `feature_name` - имя создаваемого элемента Inventor.

`cup` описывает чашку стяжки на боковой грани:

- `diameter_parameter` - имя параметра Inventor для диаметра чашки.
- `depth_parameter` - имя параметра Inventor для глубины чашки.
- `direction` - направление сверления: `positive` или `negative`.
- `feature_name` - имя создаваемого элемента Inventor.

## Порядок Работы

1. В Inventor назначить цвета нужным граням стыка.
2. Создать эскизы для каркаса:

```powershell
python 00_createSketchesКаркас_на_Зел_Жел_Кр.py
```

3. Создать эскизы для ящика:

```powershell
python 00_createSketchesЯщик_на_Син.py
```

4. Запустить нужные скрипты присадки:

```powershell
python 03_confirmat_3штКаркас_на_Красн.py
python 02_confirmat_2штКаркас_на_Жел.py
python 01_stiajkaКаркас_на_Зел.py
python 01_stiajkaЯщик_на_Син.py
```

## Эскизы

Скрипты `00_*` создают эскизы с точками присадки.

Каркас:

```text
DrillingSketch_*
```

Ящик:

```text
DrawerSketch_*
```

Если на плоскости уже есть общий эскиз, скрипт не создает дубль. Он проверяет каждую цветную грань отдельно:

```text
геометрия этой грани уже есть -> пропустить грань
геометрии этой грани нет      -> добавить в существующий эскиз
```

## Логика Точек

На каждой рабочей грани создается ось по центру длинных ребер и пять точек:

```text
крайняя левая
внутренняя левая
центральная
внутренняя правая
крайняя правая
```

Расстояние между крайними точками считается по формуле:

```text
floor((Long_edge_N - Минимальный_отступ_присадки_от_кромки_* * 2) / 32 мм) * 32 мм
```

Для каркаса используется:

```text
Минимальный_отступ_присадки_от_кромки_Каркас
```

Для ящика используется:

```text
Минимальный_отступ_присадки_от_кромки_Ящик
```

## Конфирмат

Красная грань:

```powershell
python 03_confirmat_3штКаркас_на_Красн.py
```

Создает конфирмат по двум крайним точкам и центральной точке.

Желтая грань:

```powershell
python 02_confirmat_2штКаркас_на_Жел.py
```

Создает конфирмат только по двум крайним точкам.

## Стяжка

Зеленая грань:

```powershell
python 01_stiajkaКаркас_на_Зел.py
```

Синяя грань:

```powershell
python 01_stiajkaЯщик_на_Син.py
```

Стяжка создает основные отверстия и `Stiajka cup`. Для `Stiajka cup` создается отдельный боковой эскиз, а точки чашки привязываются к центру спроецированной геометрии конца отверстия от кромки.

## Диагностика

Для анализа последних эскизов:

```powershell
python inspect_sketches.py
```

## Заметки

- Скрипты используют позднее COM-связывание.
- Размеры Inventor API обычно возвращает в сантиметрах.
- Цветовая разметка является управляющей логикой проекта: код не угадывает конструкцию, а выполняет правила по цветам.
