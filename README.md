# Автоматизация мебельной присадки в Autodesk Inventor

Набор Python-скриптов для создания эскизов и отверстий мебельной присадки в активной `.ipt`-детали Autodesk Inventor через COM.

Текущая логика больше не привязана к цветам граней. Рабочие грани выбираются вручную в Inventor перед запуском нужной команды.

## Основной сценарий

1. В Inventor выделить одну или несколько граней.
2. Запустить нужную команду:
   - `01_stiajka_2шт.py` - стяжка;
   - `02_confirmat_2шт.py` - конфирмат на две точки;
   - `03_confirmat_3шт.py` - конфирмат на три точки.
3. Скрипт сам запускает `00_createSketches.py`, создает эскиз на выделенных гранях, затем создает отверстия.
4. После завершения рабочие эскизы скрываются.

`00_createSketches.py` можно запускать отдельно, если нужно только создать эскиз на выделенных гранях.

## Требования

- Autodesk Inventor уже запущен.
- Открыта активная `.ipt`-деталь.
- Установлены Python и пакет `pywin32`.
- Python и Inventor запущены с одинаковыми правами пользователя, иначе COM-подключение может не сработать.

## Параметры Inventor

В детали должны быть пользовательские параметры:

```text
Минимальный_отступ_присадки_от_кромки_Каркас
Минимальный_отступ_присадки_от_кромки_Ящик
Стяжка_D
Стяжка_h
Стяжка_отступ
```

Если нужного параметра нет, скрипт покажет окно со списком отсутствующих параметров и остановится.

## Эскизы

`00_createSketches.py` работает только с выделенными гранями.

Для каждой выбранной грани строятся:

- ось по центру длинных ребер;
- пять точек на оси: крайняя левая, внутренняя левая, центральная, внутренняя правая, крайняя правая;
- размеры, привязанные к пользовательским параметрам отступа.

Цвет эскиза фиксированный желтый: `RGB (255, 220, 0)`.

Шаг сетки между точками кратен `32 мм`. Расстояние между крайними точками считается по формуле:

```text
floor((Long_edge_N - отступ * 2) / 32 мм) * 32 мм
```

Параметр `отступ` выбирается автоматически:

- если длинное ребро больше `400 мм`, используется `Минимальный_отступ_присадки_от_кромки_Каркас`;
- иначе используется `Минимальный_отступ_присадки_от_кромки_Ящик`.

Если на плоскости уже есть подходящий эскиз с нужным префиксом, он переиспользуется. Если геометрия для конкретной грани уже есть, эта грань пропускается.

## Быстрый запуск

Выделите грани в Inventor и запустите нужный скрипт:

```powershell
python 01_stiajka_2шт.py
python 02_confirmat_2шт.py
python 03_confirmat_3шт.py
```

Создать только эскизы:

```powershell
python 00_createSketches.py
```

Диагностика эскизов:

```powershell
python inspect_sketches.py
```

## Запуск через лаунчер

Консольный лаунчер:

```powershell
scripts\launcher.bat sketches
scripts\launcher.bat stiajka
scripts\launcher.bat confirmat2
scripts\launcher.bat confirmat3
```

Оконный лаунчер используется iLogic-правилами:

```powershell
pythonw scripts\launcher_window.py sketches
pythonw scripts\launcher_window.py stiajka
pythonw scripts\launcher_window.py confirmat2
pythonw scripts\launcher_window.py confirmat3
```

## iLogic

Готовые внешние правила лежат в папке:

```text
scripts\Создание присадки
```

Актуальные правила:

```text
01_CreateSketches.iLogicVb
02_Stiajka2.iLogicVb
03_Confirmat2.iLogicVb
04_Confirmat3.iLogicVb
```

В Inventor подключите эту папку как External Rules и добавьте нужные правила на ленту.

## Команды

| Команда | Что делает |
| --- | --- |
| `sketches` | Создает эскиз на выделенных гранях |
| `stiajka` | Создает эскиз и отверстия стяжки |
| `confirmat2` | Создает эскиз и отверстия конфирмата по двум крайним точкам |
| `confirmat3` | Создает эскиз и отверстия конфирмата по двум крайним и центральной точке |

## Настройки

Основные настройки лежат в `settings.json`.

`inventor_api` содержит служебные коды Inventor:

- `hole_direction.positive` и `hole_direction.negative` - направления сверления;
- `dimension_orientation.horizontal`, `vertical`, `aligned` - типы размеров в эскизе.

`confirmat` задает размеры отверстий конфирмата.

`stiajka` задает параметры и размеры отверстий стяжки:

- `parameters` - имена пользовательских параметров Inventor;
- `side_offset` - запасной боковой отступ, если параметр не найден;
- `outer_main`, `outer_secondary`, `inner_short`, `inner_long` - отверстия стяжки;
- `cup` - отверстие чашки стяжки.

Размеры можно задавать строками с единицами Inventor, например `"5 mm"` или `"35 mm"`.

## Структура проекта

```text
00_createSketches.py      - создание эскизов на выделенных гранях
01_stiajka_2шт.py         - стяжка по выделенным граням
02_confirmat_2шт.py       - конфирмат 2 точки по выделенным граням
03_confirmat_3шт.py       - конфирмат 3 точки по выделенным граням
inspect_sketches.py       - диагностика эскизов
settings.json             - размеры и служебные настройки
common/                   - общие функции Inventor, граней и эскизов
confirmat/                - логика конфирмата
stiajka/                  - логика стяжки
sketch/                   - построение эскизов присадки
scripts/                  - лаунчеры и iLogic-правила
```

## Важно

- Перед запуском рабочей команды обязательно выделите грани в Inventor.
- Цвет граней больше не управляет логикой.
- Рабочие скрипты сами создают нужный эскиз через `00_createSketches.py`.
- После создания отверстий использованные эскизы скрываются.
- Перед массовым запуском лучше проверить модель на копии детали.
